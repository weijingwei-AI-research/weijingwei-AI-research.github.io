## Publish with GitHub Pages

In **Settings → Pages**, select **Deploy from a branch**, **main**, **/(root)** and Save. You can then access the English and Chinese addresses above.

## Update

Edit `index.html` for English and `zh/index.html` for Chinese. The publication data is embedded in each HTML file. Any publicly released code or dataset links can be added after verifying release permissions.
